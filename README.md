# Програмний проєкт 6, варіант 2
Харченко Поліна К-28

Сопрограма генерує та виводить випадкові натуральні числа з проміжку [1, 256]. Коли поточне число відрізняється від попереднього менше ніж на 16, сопрограма призупиняється. Логіка призупинення знаходиться в контролері очікування (`WaitController`).

## Структура

| Файл | Призначення |
|------|-------------|
| `main.cpp` | розбір аргументу, запуск сопрограми, відновлення після кожного призупинення |
| `generator.h`, `generator.cpp` | сопрограма `generate(count)` |
| `wait_controller.h` | контролер очікування та awaiter, що вирішує чи призупиняти сопрограму |
| `task.h` | тип `Task` |
| `random_source.h`, `random_source.cpp` | генератор випадкових чисел |
| `CMakeLists.txt` | збирання проєкту |

## Збирання

Компілятор з підтримкою C++20:

```bash
cmake -S . -B build
cmake --build build
```

Без CMake:

```bash
g++ -std=c++20 main.cpp generator.cpp random_source.cpp -o coroutines
```

## Запуск

```bash
./coroutines [count]
```

Значення за замовчуванням: 20. Це має бути додатне ціле число, інакше програма виведе повідомлення про помилку й завершиться з кодом 1.Вхідних файлів програма не використовує.
Наприкінці виводиться кількість призупинень.
